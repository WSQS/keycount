keycount pet  __VERSION__  (Windows x64)
================================================

一只住在桌面上的宠物，顺便把你「今天敲了多少下键盘、分别是哪些键、现在打多快」
表演出来。

隐私：只存计数，不存内容
------------------------------------------------
库里只有 (日期, 小时, 键名, 次数) 四列 —— 没有按键顺序、没有字符、没有窗口标题。
这条有断言盯着（源码里的 native/test_store.cpp 会检查列名与列数）。
数据全在本机，不上传：
  %APPDATA%\Godot\app_userdata\keycount pet\keycount.db

怎么启动（两种都行，区别只在键盘焦点）
------------------------------------------------
1. 双击 start.cmd        ← 推荐
   启动前记下「此刻谁持有键盘」，宠物起来后立刻还给它。你正在打的字不受影响。

2. 双击 keycount.exe     ← 也能跑，但启动那一下键盘会被宠物夺走
   （你正在打的字会掉进宠物里，什么都不会出现；点回你的窗口即可恢复）

想开机自启：右键 start.cmd → 发送到 → 桌面快捷方式，
再把快捷方式放进：
  %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup

杀软说明（重要）
------------------------------------------------
这个程序会安装一个**全局键盘钩子**（否则非焦点窗口收不到按键）—— 这正是键盘记录器
用的同一套系统接口，所以杀软/卫士可能报「键盘记录器」，SmartScreen 也会提示
「未知发布者」（本程序未做代码签名）。

它就是 GitHub Actions 从这份源码构建出来的，自建请见：
  https://github.com/WSQS/keycount

操作
------------------------------------------------
- 左键按住宠物拖动
- 单击宠物：看今日总数
- 右键：菜单

卸载
------------------------------------------------
删掉本文件夹即可。想连数据一起清干净，再删掉
  %APPDATA%\Godot\app_userdata\keycount pet\
